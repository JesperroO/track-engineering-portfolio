# 第 1 周实作规格书

版本 1.0｜2026-10-19 补写。长期计划已有要求，本周独立规格书此前缺失；本文件不是事前已存在的验收标准。

## 本周目的

将已有遥测分析转化为车手／技师可执行的节间决定，并留下可归档、可展示的工程交接。服务银骥现场准备，不重新教授已有 delta 分析，也不是悬挂调校资格考试。

## 范围与输入

- 真实基础：P1 S06 L7／S08 L8 固定地理门、线路、油门、速度、倾角图和方法说明。
- 后续训练：明确标记的车身晃动、接缝和回弹设定模拟情景。
- 输入形式：用户口述转写；不据此评价声音、真实时长或情绪。
- 本次实际完成的是沟通与决策练习；原定限时数据接收／清洗／绘图未独立执行，不能把整套现场流程标为已完成。

## 交付

1. [README：过程档案](README.md)：原话、反馈、用户修正、题目问题及作废分支。
2. [收尾情景](final-scenario.md)：固定、完整的数据与约束。
3. [工程报告草稿](engineering-report.md)：以一页式结构区分真实证据、模拟观察、决定、验证与后续。用户回答前保持草稿，不声称验收。
4. 报告中的 run sheet 至少包含：采用设定与线路、保持条件、车手任务、技师职责、观测指标及采用／回退条件。

## 评价标准

| 维度 | 观察要求 |
|---|---|
| 简短与信息密度 | 尽早报判断和行动，避免重复；不为压短而省掉影响执行的条件 |
| 精确 | 说明比较对象、区段、设定方向及变化量；不把时间先后等同空间先后 |
| 工程判断 | 明确选方向及代价，不假装原因已确定，不把决策全部交回车手 |
| 协作 | 接住车手感受、利用技师知识、分工清楚；不以防御性免责声明替代行动 |
| 验证 | 比较整车收益，保留条件及回退值；明确新跑法或参数是否实际执行 |
| 交接 | 接手者不必阅读整个聊天也知道当前选择、理由、风险和下一步 |

不设唯一设定答案，不给无基准的总分。前三轮反馈不能追溯性套用新加约束；题目设计错误单独记录，不扣用户表现。
